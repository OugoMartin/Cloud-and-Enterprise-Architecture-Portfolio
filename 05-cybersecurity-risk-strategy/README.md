# 05 — Cybersecurity Risk & Investment Strategy

## Objective
Evaluate cybersecurity risks and use a structured model to support mitigation and investment prioritization.

## Risk Model
- **Likelihood** — probability that a threat may occur
- **Impact** — potential organizational consequence

These dimensions are used to classify risks and support a risk heat map.

## Risks Considered
- Data breaches
- API vulnerabilities
- Insider threats
- Legacy-system failures

## Prioritization Principle
Risks assessed as both high probability and high impact are treated as critical priorities for mitigation in the source project.

## Architecture Relevance
The project connects cybersecurity to enterprise architecture planning by considering data protection, system reliability, security standards, governance, and technology investment.

## Evidence Boundary
The supplied portfolio describes the model and example risk categories but does not include the original numeric risk register or full heat-map dataset. No numeric risk scores are invented in this repository.
