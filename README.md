# Cloud & Enterprise Architecture Portfolio

A professional portfolio of cloud architecture, enterprise architecture, cybersecurity risk, and infrastructure planning case studies developed by **Martin Ougo**.

## Portfolio Overview

This repository organizes academic architecture work into clear technical case studies. It demonstrates cloud infrastructure evaluation, secure AWS architecture, scalable system design, enterprise architecture modeling, cybersecurity risk assessment, and data-informed infrastructure planning.

> **Portfolio note:** These are educational case studies. Architecture descriptions and recommendations are presented as portfolio work rather than production deployments.

## Core Areas

- Cloud architecture and deployment models
- AWS infrastructure and security controls
- Scalability and high availability
- Enterprise architecture and technology strategy
- Cybersecurity risk assessment
- Capacity planning and resource optimization
- Technical documentation and stakeholder communication

## Architecture Principles Demonstrated

**Security:** least privilege, role-based access, encryption, monitoring, audit logging, and risk-based mitigation.

**Scalability:** elastic compute capacity, load distribution, managed database services, and object storage.

**Business alignment:** architecture decisions are connected to operational requirements, risk, cost, and organizational objectives.

**Documentation:** each case study follows a consistent structure: problem, objective, design or method, decisions, risks/trade-offs, and business value.
