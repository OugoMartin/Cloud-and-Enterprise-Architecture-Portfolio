# Architecture Decision Records

This directory is reserved for concise Architecture Decision Records (ADRs) as the portfolio evolves.

```text
# ADR-NNN: Decision title
Status: Proposed | Accepted | Superseded

## Context
What problem or constraint requires a decision?

## Decision
What architecture choice was made?

## Rationale
Why was it selected?

## Consequences
What benefits, risks, costs, and trade-offs follow?
```

ADRs should document actual decisions supported by project evidence rather than retroactively inventing implementation details.
